# KaraScore

> 100% Client-Side YouTube Karaoke Pitch Scoring Web App with Zero Recurring Infrastructure Cost.

KaraScore enables singers to search or link any YouTube karaoke backing track, sing in real time with high-precision pitch detection, and receive automated 2-tier scoring (Exact Melody and Smart Vocal Score).

## Quick Start

```powershell
npm install
npm run dev
```

## Available Scripts

- `npm run dev`: Start Vite development server
- `npm run typecheck`: Run TypeScript static check (`tsc --noEmit`)
- `npm run lint`: Run ESLint check
- `npm run test`: Run Vitest unit tests
- `npm run build`: Production client bundle build
- `npm run verify`: Run full verification pipeline (`typecheck && lint && test && build`)
